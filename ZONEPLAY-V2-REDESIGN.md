# LIFEISGAMETZ — ZonePlay V2 Redesign

This build keeps the existing GameHub HTML pages, backend, API endpoints, JSON data, cart, checkout, movies, live, academy, chat, AI and admin functionality while applying a new ZonePlay-inspired gaming marketplace shell.

## Visual structure
- Fixed gaming navigation rail
- Global search/top bar
- Trending game cards
- Platform/category shelves
- Hero product area
- Offers and library panels
- Live football area
- Academy/course area
- Mobile bottom navigation
- Responsive dark neon gaming UI

## Important
This is a ZonePlay-inspired design pattern, not a copy of any third-party site.
