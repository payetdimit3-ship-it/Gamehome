# LIFEISGAMETZ Design Reference

The `design-reference/` folder contains the screenshots supplied in the New Folde ZIP. They are kept as visual references for the redesigned pages. They are not used as page backgrounds or product artwork.

## Design direction
- Dark navy/black UI
- Neon purple/blue/cyan accents
- Persistent left sidebar + top search/header
- Responsive mobile navigation
- Product/game cards with image, category, price and CTA
- Admin dashboard with quick actions, analytics, content management and system status
- Checkout with clear order summary, discount and payment status

The existing AI provider implementation in `server.js` is intentionally preserved.
